# Google Drive upload checklist

Create one folder, e.g. `Ajaia Docs — Adit Shah`, and upload:

- [ ] Entire source project (zip or folder) — exclude `data/store.json` and `node_modules` if any
- [ ] `README.md`
- [ ] `ARCHITECTURE.md`
- [ ] `AI_WORKFLOW.md`
- [ ] `SUBMISSION.md` ← main index for reviewers
- [ ] `VIDEO_URL.txt` ← **paste Loom/YouTube URL after recording**
- [ ] `WALKTHROUGH_SCRIPT.md` (optional helper; fine to include)
- [ ] `screenshots/` folder
- [ ] `samples/standup-notes.md`

In the Drive folder description or a top-level note, also paste:

- Live URL: https://ajaia-docs-ashah.fly.dev/
- GitHub: https://github.com/CodeRockerr/ajaia-docs

Share the Drive folder link with **anyone with the link can view**.
